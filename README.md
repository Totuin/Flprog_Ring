# Flprog_Ring 1.0.1

Библиотека FLProg для обмена типизированными переменными между устройствами по кольцевому UART. Данная ревизия проведена с сохранением существующих публичных имён и формата кадров.

## Зависимости

- `Flprog_Utilites` (проверено с ревизией 1.0.1): `flprogUtilites.h` и интерфейс `FlprogAbstractUartExecutor` из `flprogUartBase.h`.
- Реализация UART из программы/платформы (`FlprogUartExecutor` либо пользовательский потомок интерфейса).
- Для аппаратного UART реальный драйвер RT_HW применяется **только как зависимость** и в ревизии не изменялся.

## Формат обмена

```
0x01 <sender:ASCII decimal uint32> 0x02 <variableId:ASCII decimal uint32> 0x03 <value:ASCII> 0x04
```

- `sender` — индекс устройства-отправителя, `variableId` — идентификатор переменной.
- В режиме `isSingleMode(true)` входящие сообщения не пересылаются дальше.
- В кольцевом режиме чужие корректные сообщения перенаправляются на тот же UART. Кадры с собственным индексом не пересылаются.
- В `pool()` принимается не более одного завершённого кадра за вызов. Между вызовами сохраняется состояние неполного кадра; пауза между байтами в 100 мс приводит к сбросу незавершённого кадра.
- Локальный вызов `value(...)` помечает переменную для следующей отправки. Входящий `setValueString(...)` меняет значение без повторной отправки.

**Ограничение протокола:** байт `0x04` внутри строкового значения считается концом кадра, экранирование управляющих байтов в протоколе отсутствует. Формат сохранён для совместимости, менять его можно только одновременно на всех устройствах. Передача `float` сохраняет исторические **два знака после запятой**.

## Использование

Пример в `examples/FLProgRing/FLProgRing.ino` теперь содержит обязательный аргумент `FlprogAbstractUartExecutor*` в конструкторе и предварительный `beginUart()`. Порт и схему подключения выбирают в зависимости от платы. Если выбран UART, занятый USB Serial Monitor, это может мешать обмену.

Указатели, зарегистрированные через `addReadVariable()` и `addSendVariable()`, **не передают владение** переменными объекту `FLProgRing`. Экземпляры переменных и UART должны существовать дольше самого объекта кольца. Внутренние массивы указателей освобождаются деструктором `FLProgRing`. Экземпляр `FLProgRing` запрещено копировать.

## Состав

- `src/` — исходники, исправления и русские комментарии;

## Что проверено

Проведена статическая ревизия и автономная сборка `g++ -std=c++11 -Wall -Wextra -Wpedantic -Werror` с AddressSanitizer/UndefinedBehaviorSanitizer. Успешно проверены обработка разбитых кадров, ретрансляция, полные 32-битные идентификаторы и значения, некорректные поля, тайм-ауты, переполнение `millis()`, режим пропуска вызовов и защита от `nullptr` UART.

**Проверка Arduino IDE/FLProg с реальными зависимостями и аппаратная проверка кольца ещё не выполнены.**
